# Pegboard

My personal site in the style of a pegboard!


## Sections

- About me area
    - My profile picture!
    - Small info section including what programs I use

- Link shelf
    - Includes links to all platforms you can find me on!

- Keychain project area
    - Each keychain links to one of my projects on Stardance!

- Vinyl shelf
    - Has some of my favorite albums
    - Clicking on them directs to the album on spotify
